# mk-webs-resource

## 项目简介

`mk-webs-resource` 是一个用于归档和发布独立 HTML 页面的仓库。本仓库不针对任何特定网站或域名，仅作为通用 HTML 资源的存储与展示空间。

## 目录结构

```
mk-webs-resource/
├── pages/          # 存放独立的 HTML 页面文件
├── assets/         # 页面引用的静态资源（CSS、JS、图片等）
└── docs/           # 相关文档或说明文件（可选）
```

- `pages/`：每个 HTML 文件对应一个独立的页面，文件名应具有描述性。
- `assets/`：按需组织子目录，资源文件与页面引用路径保持一致。
- `docs/`：可放置项目使用说明、贡献指南等附加文档。

## 页面归档说明

本仓库中的 HTML 页面主要用作：
- 历史版本的快照存档
- 临时或实验性页面的发布
- 跨项目共享的通用页面模板

每个页面均独立完整，不依赖外部动态服务。页面内容可能随时间更新，但旧版本可通过 Git 历史追溯。

## 使用方式

1. 直接通过 GitHub Pages 或静态托管服务访问 `pages/` 目录下的 HTML 文件。
2. 如需引用资源，请使用相对路径指向 `assets/` 目录。
3. 本地预览时，建议使用本地 HTTP 服务器以避免跨域问题。

## 维护说明

- 本仓库由维护者不定期更新，新增页面或修正内容。
- 欢迎通过 Issue 提交页面归档建议或报告链接失效问题。
- 提交 Pull Request 时，请确保 HTML 文件结构完整、资源引用正确。
- 不建议在本仓库中存放包含敏感信息或动态后端依赖的页面。
